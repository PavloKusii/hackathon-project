# Етичний Вартовий (Ethical Guard)

«Етичний Вартовий» (Ethical Guard) — це веб-платформа для інтерактивного моделювання, симуляції та розбору складних етико-правових і професійних дилем. Платформа дає змогу моделювати реальні ситуації з вибором дій, аналізувати наслідки ухвалення рішень та проводити інтерактивні групові тренінги й навчальні сесії в режимі реального часу.

Система підтримує як індивідуальне самостійне проходження кейсів з отриманням персонального підсумку та правового розбору, так і командні заняття через віртуальні кімнати за допомогою коду або QR-коду.

## Ключові можливості платформи

* Лінійні та розгалужені сценарії (Граф виборів):

  * Проходження стандартних послідовних ситуацій або розгалужених варіантів розвитку подій, де кожне рішення впливає на наступний крок.

  * Практичний аналіз правових і нормативних наслідків кожного вибору з посиланнями на законодавчу базу.

* Інтерактивні групові сесії в реальному часі:

  * Автоматична генерація унікального коду кімнати та QR-коду для швидкого підключення учасників.

  * Проведення занять із телефону чи будь-якого іншого мобільного пристрою слухачів.

  * Підтримка анонімного входу або синхронізації з особистим кабінетом.

* Гнучка система таймерів та контролю часу:

  * Обмеження часу на весь кейс загалом або окремо на кожен крок/завдання.

  * Автоматичний фініш та обробка ситуацій із вичерпанням часу.

* Комплексна аналітика занять та звітність:

  * Автоматичний підрахунок середніх балів групи за 3 ключовими етичними показниками.

  * Виявлення ключових проблемних точок (етапів із найбільшою кількістю ризикованих рішень) та сильних рішень групи.

  * Персональний детальний розбір відповідей кожного учасника для викладача/організатора.

* Інтерактивна Бібліотека норм:

  * База нормативно-правових актів та етичних стандартів для попереднього ознайомлення слухачів перед складанням кейсів.

## Ролі користувачів

Платформа передбачає чітке розмежування прав та рівнів доступу:

### 1. Гість (без обов'язкової реєстрації)

* Відвідувач системи без авторизації в акаунті.

* Має доступ до перегляду Бібліотеки норм та проходження публічних кейсів.

* Може приєднуватися до групових занять за кодом кімнати чи QR-кодом.

### 2. Учасник (зареєстрований користувач)

* Користувач, який пройшов реєстрацію та має особистий акаунт.

* Повний доступ до Бібліотеки норм, усіх публічних кейсів та групових кімнат.

* Усі результати індивідуальних та групових проходжень зберігаються в особистому кабінеті («Моя статистика»).

### 3. Організатор

* Авторизований користувач із правами викладача / фасилітатора.

* Створення та проведення групових сесій у режимі реального часу, налаштування таймерів, отримання розширеного звіту та аналітики занять.

* Створення та редагування власних складних розгалужених сценаріїв (конструктор кейсів та граф виборів).

* Надсилання власних кейсів на перевірку Головному адміністратору для їх публікації в загальному каталозі сайту.

* Має можливість самостійно проходити тести для перевірки та саморозвитку.

### 4. Супер-адміністратор (Головний адміністратор)

* Системна роль із найвищими правами доступу.

* Управління користувачами: адміністрування акаунтів, призначення та зміна ролей користувачів.

* Модерація контенту: перевірка, погодження, відхилення або публікація нових кейсів у загальний доступ.

* Можливість створювати віртуальні кімнати, проводити заняття та переглядати аналітику будь-яких сесій.

## Оцінювання та етичні шкали (Реалізовано)

Оцінювання рішень здійснюється на основі 3 ключових метрик:

1. **Доброчесність (Integrity)**: чесність, неупередженість, дотримання етичних норм та законодавчих вимог.

2. **Довіра та репутація (Trust & Reputation)**: авторитет, рівень публічної довіри та професійна іміджева складова.

3. **Ефективність (Effectiveness)**: досягнення поставленої мети, раціональність використання ресурсів та дієвість обраного рішення.

## Можливості розширення проєкту (Планується)

Надалі платформу «Етичний Вартовий» можна розширити такими функціями та модулями:

1. **Генерація кейсів за допомогою штучного інтелекту (AI-Assistant)**:

   * Інтеграція LLM для автоматичного створення нових правових та етичних сценаріїв за заданою галуззю або нормативним актом.

   * Автоматичний генератор гілок відповідей та правових коментарів на основі чинного законодавства.

2. **Інтеграція з навчальними системами (LMS)**:

   * Підтримка протоколів LTI (Learning Tools Interoperability) для безшовного підключення платформи до Moodle, Canvas, Google Classroom тощо.

   * Автоматичний експорт оцінок та звітів проходження у журнал успішності.

3. **Командний / Рольовий режим проходження (Multi-Role Simulations)**:

   * Можливість розподілу ролей у груповому занятті (наприклад: прокурор, адвокат, етичний комітет, журналіст), де рішення однієї сторони змінюють доступні кроки для іншої.

4. **Розширена аналітика та PDF/Excel-звіти**:

   * Формування розширеного вивантажуваного PDF-звіту за результатами групової сесії з графіками динаміки шкал для презентації або архівування.

5. **Гейміфікація та сертифікація**:

   * Система досягнень, бейджів та рейтингів для учасників.

   * Автоматична генерація електронних сертифікатів про успішне проходження етичних тренінгів.

6. **Мобільний додаток (PWA / Mobile)**:

   * Перетворення системи на Progressive Web App або випуск нативного мобільного додатка для зручнішого проходження тренінгів.

## Технологічний стек

* Frontend: React.js, Tailwind CSS, SVG-індикатори та діаграми, qrcode.react, Socket.IO Client.

* Backend: Node.js, Express.js, Socket.IO Server, JSON Storage system.

* Протоколи зв'язку: HTTP REST API + WebSockets (Socket.IO) для передачі стану кімнати в реальному часі.

## Встановлення та запуск проєкту

> **Мережева вимога для групового заняття:**
> Щоб учасники могли підключатися до кімнати зі своїх телефонів, комп'ютер організатора (на якому запущено сервер) та мобільні пристрої слухачів мають бути підключені до однієї мережі Wi-Fi / локальної мережі.

### Крок 1. Запуск бекенду (Backend)

1. Відкрийте термінал (або термінал у вашій IDE — IntelliJ IDEA / VS Code).

2. Перейдіть у папку бекенду:

   ```bash
   cd backend
   ```

3. Встановіть необхідні залежності:

   ```bash
   npm install
   ```

4. Запустіть сервер:

   ```bash
   npm start
   ```

   *Сервер бекенду запуститься на порту 4000 (`http://localhost:4000`).*

### Крок 2. Запуск фронтенду (Frontend)

1. Відкрийте новий вкладку або вікно терміналу.

2. Перейдіть у папку фронтенду:

   ```bash
   cd frontend
   ```

3. Встановіть необхідні залежності:

   ```bash
   npm install
   ```

4. Запустіть веб-додаток у режимі розробки:

   ```bash
   npm run dev
   ```

   *Фронтенд запуститься та видасть адресу у локальній мережі.*

## Сценарії роботи з платформою

### Сценарій 1. Перший вхід та індивідуальне проходження

1. Користувач відкриває головну сторінку та обирає «Бібліотека норм» для ознайомлення із законами.

2. Обирає будь-який публічний кейс для самостійного проходження.

3. Обирає варіанти дій на кожному кроці, спостерігаючи за динамікою шкал та читаючи розбір аналізу.

4. Якщо користувач увійшов під акаунтом Учасника, підсумок автоматично зберігається в «Моїй статистиці».

### Сценарій 2. Проведення групового заняття Організатором

1. Організатор входить у свій акаунт і відкриває розділ «Групове заняття».

2. Обирає кейс, вказує назву групи, налаштовує обмеження часу та натискає «Створити кімнату».

3. Учасники сканують QR-код або переходять за посиланням з кодом кімнати на своїх телефонах.

4. Учасники проходять кейс і натискають фінальну кнопку «Завершити та переглянути підсумок».

5. Організатор натискає «Завершити заняття», після чого всі дані автоматично зберігаються та відображаються у розділі «Статистика занять».
